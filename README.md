# DavanteDent - Sistema de Gestión de Citas 🦷

Una aplicación web dinámica para la gestión de citas diarias de una clínica dental. Este proyecto implementa un sistema CRUD completo en el lado del cliente (Frontend) utilizando Vanilla JavaScript, manipulando el DOM y persistiendo los datos mediante el almacenamiento local del navegador.

## 🚀 Características Principales

*   **Gestión de Citas (CRUD):** Creación, lectura, actualización y eliminación de registros de pacientes.
*   **Validación de Formularios:** Comprobación estricta de tipos de datos (por ejemplo, restricción numérica para teléfonos) y campos obligatorios antes de procesar la información.
*   **Persistencia de Datos:** Uso de `LocalStorage` para garantizar que la información de las citas no se pierda al recargar la página o cerrar el navegador.
*   **Interfaz Dinámica:** Actualización de la tabla de registros en tiempo real sin necesidad de recargar la vista, incluyendo el manejo de estados vacíos.

## 🛠️ Tecnologías Utilizadas

*   **HTML5:** Estructura semántica del formulario de captura y la tabla de presentación.
*   **CSS3:** Variables de color corporativas, diseño fluido con Flexbox y estilos de interfaz de usuario.
*   **JavaScript (ES6+):** Lógica de negocio, Programación Orientada a Objetos (POO) mediante instanciación de clases, y manipulación directa del Document Object Model (DOM).

## ⚙️ Instalación y Uso

Al ser un proyecto Frontend estático, no requiere la instalación de dependencias externas ni el levantamiento de un servidor local.

1. Clona este repositorio en tu máquina local:
   git clone https://github.com/Carlos051403/davantedent-citas.git
2. Navega hasta el directorio del proyecto.
3. Abre el archivo `index.html` directamente en cualquier navegador web moderno (Chrome, Firefox, Edge).
